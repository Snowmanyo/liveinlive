# Concert Archive 🎵

我的演唱會收藏儀表板 - 追蹤和分析你的演唱會體驗

## 功能特色

- 📊 數據總覽與統計分析
- 🎤 表演者統計（專場/拼盤分開計算）
- 🗓️ 時間軸與月曆檢視
- 🏟️ 場館與城市分布
- ⭐ 演唱會之最
- 🎫 數位票卡收藏

## 使用方式

1. 上傳你的演唱會記錄 CSV 檔案
2. 瀏覽各項統計數據
3. 建立你的演唱會票卡收藏

## CSV 格式範例
```csv
場次,日期,表演者,Live Tour,類型,地點,場地,座位,票價,嘉賓
1,2024年1月1日,五月天,人生無限公司演唱會,專場,台北,小巨蛋,A區,3500,
```
